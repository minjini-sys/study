# AWS re:Invent 2026 세션 카탈로그 공개

날짜: 2026-09-09  
출처: [AWS re:Invent 2026 - Session Types & Learning Formats](https://aws.amazon.com/events/reinvent/sessions/how-youll-learn/)

## 오늘의 AWS 소식

AWS re:Invent 2026의 세션 카탈로그가 공개되었다.

AWS는 re:Invent에서 2,200개 이상의 세션을 제공하며, 이 중 약 70%는 실습과 토론 중심의 인터랙티브 형식이라고 설명한다.

## 핵심 내용

re:Invent 2026에서는 단순 발표 세션뿐 아니라 직접 만들고 실습하는 형식의 학습 기회가 많다.

대표적인 세션 형식은 다음과 같다.

- Breakout sessions
- Lightning talks
- Chalk talks
- Code talks
- Builders' sessions
- Workshops
- Labs
- Gamified learning
- Exam prep sessions
- Bootcamps

## 왜 중요한가

AWS 서비스는 매년 빠르게 바뀐다.

re:Invent는 AWS의 새 서비스와 기능이 대규모로 발표되는 행사이기 때문에, 세션 카탈로그를 보면 AWS가 어떤 분야를 중요하게 보고 있는지 파악할 수 있다.

이번 안내에서 특히 눈에 띄는 주제는 다음과 같다.

- Agentic AI
- Security
- Compute
- Databases
- Serverless
- Architecture

## 학습 관점에서 정리

re:Invent 세션은 수준별로 나뉘어 있다.

| 수준 | 의미 |
| --- | --- |
| 100 level | 기초 |
| 200 level | 중급 |
| 300 level | 고급 |
| 400 level | 전문가 |
| 500 level | Distinguished 수준 |

처음 공부할 때는 100~200 level로 개념을 잡고, 자격증이나 실무 아키텍처 관점에서는 300 level 이상을 참고하면 좋다.

## 보안 세션

AWS는 2026년부터 re:Inforce를 re:Invent 안에 포함했다.

보안 콘텐츠는 행사 전체 기간 동안 제공되며, 12월 3일 목요일에는 보안 실무자를 위한 집중 세션이 열린다.

AI 도입이 늘어나면서 보안, 권한, 로그, 데이터 보호는 더 중요해지고 있다.

## 시험 관점에서 정리

SAP-C02 관점에서는 re:Invent 세션 자체보다 다음 포인트를 보는 것이 좋다.

- 새 서비스가 어떤 문제를 해결하는지
- 기존 아키텍처 선택지가 어떻게 바뀌는지
- 보안, 비용, 안정성, 성능 중 어떤 축에서 개선이 있는지
- 다중 리전, 재해 복구, 운영 자동화와 연결되는지

## 같이 보면 좋은 학습 포인트

AWS Skill Builder에서는 re:Invent 세션과 함께 자격증 시험 준비 학습 경로를 병행하면 좋다.

특히 SAP-C02를 준비한다면 아키텍처, 보안, 고가용성, 비용 최적화, 마이그레이션 관련 세션을 우선순위로 보면 된다.

참고: [AWS Skill Builder](https://skillbuilder.aws/)
