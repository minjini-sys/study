# AWS Summit Tel Aviv 2026 개최

날짜: 2026-09-10

## 오늘의 AWS 소식

AWS Summit Tel Aviv 2026이 2026년 9월 10일 Expo Tel Aviv에서 열렸다.

AWS Summit은 AWS 사용자, 개발자, 아키텍트, 파트너가 모여 클라우드와 AI 관련 최신 기술을 배우는 무료 오프라인 행사이다.

이번 Tel Aviv Summit은 클라우드 마이그레이션부터 AI까지 다양한 주제를 다루며, 키노트, 기술 세션, 핸즈온 실습, 파트너 엑스포를 포함한다.

## 주목할 주제

이번 행사에서 강조되는 큰 흐름은 클라우드와 AI의 결합이다.

특히 다음 주제가 중요하다.

- Agentic AI
- Generative AI
- Serverless computing
- Cloud migration
- Architecture best practices
- Security
- Cost optimization

AWS는 AI를 단순 모델 사용이 아니라 실제 비즈니스 문제 해결, 운영 자동화, 보안 통제와 연결해서 다루고 있다.

## AWS GameDay: Generative AI Challenge

Agenda에서 눈에 띄는 부분은 AWS GameDay: Generative AI Challenge이다.

AWS GameDay는 실제 운영 환경과 비슷한 시나리오에서 문제를 해결하는 실습형 학습 방식이다.

생성형 AI Challenge는 단순히 서비스를 설명하는 것이 아니라, 참가자가 직접 AWS 서비스를 조합해 문제를 풀도록 설계된 형식으로 볼 수 있다.

이런 학습은 자격증 공부에서도 도움이 된다.

문제에서 "어떤 서비스를 선택해야 하는가"를 판단하려면 서비스 이름 암기보다 요구 사항, 제약 조건, 운영 상황을 읽는 능력이 필요하기 때문이다.

## 시험 관점에서 정리

SAP-C02 관점에서는 AWS Summit 같은 행사를 다음 방식으로 활용할 수 있다.

- 새 서비스가 어떤 문제를 해결하는지 확인한다.
- AI, 서버리스, 마이그레이션, 보안이 실제 아키텍처에서 어떻게 연결되는지 본다.
- 키노트보다 300~400 레벨 세션에서 설계 의사결정 기준을 확인한다.
- 실습형 세션을 통해 장애 대응, 배포, 모니터링 흐름을 익힌다.
