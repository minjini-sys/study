# AWS Agentic Shopping Assistant에 추가된 7가지 기능

- 정리 날짜: 2026-09-27
- 원문 게시일: 2026-09-26
- 공식 출처: [AWS for Industries Blog - Introducing seven new features of the Agentic Shopping Assistant on AWS](https://aws.amazon.com/blogs/industries/introducing-seven-new-features-of-the-agentic-shopping-assistant-on-aws/)

## 핵심 내용

AWS가 리테일 기업을 위한 생성형 AI 솔루션인 Agentic Shopping Assistant on AWS에 7가지 기능을 추가했다. 이 솔루션은 고객의 자연어 요청을 이해하고 이미지, 가격, 빠른 답변이 포함된 상품 카드를 추천하며 배송, 반품, 매장 정책에 관한 질문에도 답한다.

솔루션은 리테일 기업의 AWS 계정 안에서 실행되며 기업이 코드와 고객 데이터를 직접 통제한다. 완성된 SaaS 제품을 구독하는 방식이 아니라 AWS 서비스로 구성된 솔루션을 자사 환경에 배포하고 브랜드와 업무 방식에 맞게 확장하는 형태다.

## 새로 추가된 7가지 기능

1. 셀프서비스 관리자 포털: 비즈니스 담당자가 브랜드 말투 프롬프트, 상품 카탈로그, 표준 운영 절차와 MCP 도구를 직접 관리한다. 변경 이력과 원클릭 복원 기능도 제공한다.
2. 장기 기억: Amazon Bedrock AgentCore Memory와 Amazon S3의 대화 기록을 이용해 이전 대화와 고객 선호를 다음 방문에서도 이어간다.
3. 멀티모달 검색 및 음성 대화: 고객이 상품 사진을 업로드하면 비슷한 색상, 스타일, 카테고리의 상품을 찾는다. Amazon Nova Sonic을 이용한 음성 입력과 음성 답변도 지원한다.
4. 대화 기록 선택기: 날짜와 자동 생성된 주제별로 이전 대화를 찾아보고 기존 쇼핑 상담을 다시 이어갈 수 있다.
5. 장바구니 인식 및 관리: 대화로 상품 추가와 제거, 수량·크기·옵션 변경을 처리하고 중복 상품, 연관 상품, 예산에 맞는 대안을 제안한다.
6. Shopify 통합: Universal Commerce Protocol을 사용해 별도의 API 매핑 없이 Shopify 카탈로그와 장바구니를 연결한다.
7. 대화형 인텔리전스 대시보드: 실시간 수요, 인기 카테고리, 카탈로그 누락, AI 분석과 세션 재생을 제공한다. 지연 시간, 토큰 사용량, 도구 오류율과 Guardrail 동작도 함께 보여준다.

## 왜 중요한가

기존 온라인 쇼핑 검색은 고객이 정확한 상품명이나 필터를 알아야 원하는 결과를 얻기 쉽다. 대화형 쇼핑 에이전트는 목적, 취향, 예산과 상황을 자연어로 파악해 상품 탐색부터 장바구니 관리까지 하나의 대화로 연결한다.

리테일 기업 관점에서는 고객이 어떤 표현으로 상품을 찾는지, 어떤 상품이 부족한지와 같은 의도 데이터를 직접 확보할 수 있다. 관리자 포털과 운영 대시보드가 추가되면서 개발자만이 아니라 상품기획, 마케팅, 운영 담당자도 에이전트의 동작과 품질을 관리할 수 있게 됐다.

## 서비스 및 아키텍처 관점

구체적인 구현은 기업 환경에 따라 달라지지만 핵심 흐름은 다음과 같이 볼 수 있다.

1. 웹이나 모바일 쇼핑 화면에서 텍스트, 음성 또는 이미지 요청을 받는다.
2. AI 에이전트가 고객 프로필, 대화 기록, 상품 카탈로그와 매장 정책을 조회한다.
3. 필요한 경우 MCP 도구를 호출해 재고, 배송, 가격, 장바구니 시스템과 연결한다.
4. Amazon Bedrock 기반 모델이 상황에 맞는 추천과 답변을 생성한다.
5. AgentCore Memory와 Amazon S3가 장기 기억 및 대화 이력을 지원한다.
6. Guardrail과 운영 대시보드가 품질, 안전성, 지연 시간과 비용을 관찰한다.

기존 장바구니 시스템을 교체하지 않고 연결할 수 있으며 로그인 사용자와 비회원 사용자 모두를 지원한다. Shopify 환경은 UCP를 통해 통합 작업을 단순화할 수 있다.

## 보안 및 운영 관점

- 고객 프로필, 구매 기록과 대화 내용은 개인정보이므로 수집 목적, 보존 기간과 삭제 절차를 명확히 한다.
- AgentCore Memory와 S3 데이터에 암호화, 최소 권한 IAM 정책과 접근 로그를 적용한다.
- 외부 MCP 도구에는 필요한 기능만 허용하고 자격 증명을 에이전트 프롬프트에 노출하지 않는다.
- 장바구니 변경이나 구매처럼 상태를 바꾸는 작업에는 사용자 확인과 멱등성 처리를 적용한다.
- 관리자 포털의 프롬프트 변경은 버전 이력과 승인 절차를 남기고 품질 저하 시 이전 버전으로 복원한다.
- 토큰 사용량, 응답 지연, 도구 오류, Guardrail 차단률과 추천 전환율을 함께 관찰한다.
- 이미지와 음성 입력도 악성 콘텐츠나 프롬프트 인젝션의 경로가 될 수 있으므로 검증 및 필터링한다.

## 시험 관점 정리

- Amazon Bedrock은 여러 파운데이션 모델을 API로 사용하는 완전관리형 생성형 AI 서비스다.
- Amazon Bedrock AgentCore는 에이전트 실행, 기억, 도구 연결과 관측성을 지원한다.
- Amazon S3는 대화 기록과 같은 객체 데이터를 내구성 있게 저장할 수 있다.
- 생성형 AI 시스템에도 최소 권한, 저장 및 전송 암호화, 모니터링 원칙이 동일하게 적용된다.
- 상태 변경 작업은 인증, 권한 확인, 사용자 승인과 감사 로그를 고려해야 한다.
- 개인화 서비스에서는 성능뿐 아니라 데이터 프라이버시와 책임 있는 AI 정책이 중요하다.

## 같이 보면 좋은 학습 포인트

- Amazon Bedrock AgentCore Memory와 Gateway
- Amazon Bedrock Guardrails
- Amazon Nova Sonic의 음성 대화 처리
- 검색 증강 생성(RAG)을 이용한 상품 및 정책 검색
- Model Context Protocol(MCP) 도구 보안
- Amazon S3 객체 암호화와 수명 주기 정책
- 전자상거래 장바구니 작업의 멱등성 설계

## 한 줄 정리

Agentic Shopping Assistant on AWS의 새 기능은 상품 추천을 넘어 기억, 이미지·음성 검색, 장바구니, Shopify와 운영 분석을 연결해 대화 시작부터 구매까지 이어지는 리테일 AI 경험을 만든다.
