# 네트워크 계층의 핵심(2)

공인 IP와 사설 IP

공인 IP는 ISP나 공인 IP 등록 업체에서 등록을 하며 인터넷에서 사용되는 IP이다.

사설 IP는 사설 네트워크에서 사용되는 IP로 다른 사설 네트워크의 IP와 겹칠 수 있다

[공인 IP로 사용 안되는 사설 IP 대역]

라우터: 최적의 경로를 찾아준다

NAT: 사설 IP와 공인 IP를 변환해주어 사설 IP에서도 인터넷에 접근할 수 있게 해준다. 라우터와 공유기에 이 기능이 탑재되어 있다.

동적할당과 DHCP

IP를 정적할당하는 것은 사람이 하는 것이다. 명령어 뭐였지

동적할당은 DHCP서버가 해준다.

1. DHCP discover

클라이언트가 0.0.0.0/0 디폴트 IP주소로 DHCP 서버를 찾는다.

2. DHCP offer

DHCP서버가 IP 주소와 서브넷 마스크, 임대 기간을 설정해서 보낸다

3. DHCP request

offer에 대한 응답을 클라이언트가 DHCP 서버에게 보낸다.

4. DHCP ACK

request를 받고 승인을 DHCP서버가 해준다.

DHCP는 임대 기간을 늘릴 수 있다 임대 기간 연장을 기간 끝나기 전에 2번할 수 있고 둘다 실패하면 회수한다.

## 3. 라우팅

3-1. 홉

다른 라우터나 호스트에게 전달되는 것을 말한다.

3-2. 라우팅 테이블

라우팅을 할때 테이블의 정보를 이용한다.

| 구분 | 설명 |
| --- | --- |
| 수신지 IP 주소 |  |
| 다음 홉(게이트웨이) | 전달될 인터페이스나 IP |
| NIC | 패킷을 전달할 경로 |
| 메드윅 | 전달하는 데 드는 비용으로 적은 곳에 라우팅함 |

3-3. 디폴트 라우트

0.0.0.0/0으로 모든 IP 주소를 뜻한다.

수신지 IP주소가 라우팅 테이블에 없을 때 이를 사용한다. 주로 기본 게이트웨이로 보낸다.

기본 게이트웨이는 공유기를 말한다.

3-4. 정적 라우팅과 동적 라우팅

정적 라우팅은 라우팅 테이블을 사람이 직접 추가하는 것을 말한다.

동적 라우팅은 <mark>자동으로 라우팅 테이블을 만드는 것으로 수시로 변할 수 있다.</mark>

3-5. AS Autonomous System

라우터들끼리 통신하는 <mark>집단 네트워크</mark>를 말한다.

ASBR로 AS끼리 통신도 가능하다.
