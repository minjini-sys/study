## 1. 이더넷

케이블과 프레임의 방법을 말한다

IEEE.802.3이 표준이다

### 1-1. 통신 매체 표기 형태

전송거리Base-추가 특성

Base는 변조 타입을 말한다(베이스밴드(이외의 변조 타입도 존재))

추가특성으로는 최대 전송 거리, 물리 계층 인코딩 방식, 레인 수를 나타낸다

### 1-2 통신 매체 종류

| 구분 | 종류 |
| --- | --- |
| C | 동축 케이블 |
| T | 트위스티드 페어 케이블 |
| S | 단파장 광섬유 케이블 |
| L | 장파장 광섬유 케이블 |

### 1-3 이더넷 프레임

| 프리앰블(8B) | 송신지 MAC 주소(6B) | 수신지 MAC 주소(6B) | 타입/길이(2B) | 페이로드(데이터)(42~1500B) | FCS(4B) |
| --- | --- | --- | --- | --- | --- |

- 프리앰블

프레임의 시작을 알린다 앞의 7B는 101010이고 뒤의 1B는 10101011이다

- 송신지와 수신지 MAC 주소

window의 경우 getmac -v 또는 ipconfig /all 명령어를 통해 볼 수 있다

MAC 주소는 거의 바뀌지 않고 거의 유효하다(아닐 수도 있다는 뜻! MAC주소는 NIC가 가지는 주소로 뒤에서 설명하겠다)

-타입/길이

길이가 1500이하일 경우 길이를 나타내고 이상일 경우 타입을 나타낸다 타입은 많으니 굳이 외우지 않아도 된다

| 타입 | 프로토콜 |
| --- | --- |
| 8000 | IPv4 |

- 데이터

42B이하일 경우 패딩으로 0으로 채운다

- FCS

오류를 검출한다. 수신지는 프리앰블을 제외한 필드값을 CRC(순환중복검사)를 통해 나온 값을 FCS에 넣고, 송신지는 프리앰블과 FCS를 제외한 필드값을 CRC를 통해 나온 값이 FCS와 같은지 비교해 오류를 검출한다.

## 2. NIC와 케이블

### 2-1. NIC

네트워크 인터페이스 카드이다. 카드라는 이름이 붙은 이유는 예전에 카드로 되어 있었기 때문이다.

NIC당 하나의 MAC 주소를 가진다

<mark>자신과 관련 없는 MAC 주소가 송신될 경우 폐기하고 FCS 필드를 통해 잘못된 프레임을 폐기한다</mark>

<mark>NIC마다 지원되는 속도가 다르다</mark>

### 2-2. 트위스티드 페어 케이블

구리선과 커넥터로 이용되어 있다

커넥터는 RJ-45이다

노이즈가 발생하는데 이를 감싸 노이즈를 없앤다(차폐)

| 구분 | 설명 |
| --- | --- |
| U | 실드 없음 |
| S | 브레이브 실드 |
| F | 포일 실드 |

### 2-3. 광케이블

내부는 클래딩, 코어로 되어있다

| 싱글 모드 광케이블 | 멀티 모드 광섬유 케이블 |
| --- | --- |
| 지름이 작다 | 지름이 크다 |
| 빛의 경로가 적다-> 모드가 하나다 | 모드가 여러개다 |
| 노이즈가 적다 | 노이즈가 많다 |
| 비용이 높다 | 비용이 적다 |
| 장거리 전송 | 단거리 전송 |
| 장파장 이용 | 단파장 이용 |

## 3. 허브

물리계층 네트워크 장비로 반이중 통신(단방향)이다. 또한 물리 계층은 주소가 없다

### 3-1. 콜리전 도메인

단방향이기에 충돌이 발생하게 된다 이 충돌이 발생할 수 있는 영역이 콜리전 도메인이다

### 3-2. CSMA/CD

콜리전 도메인을 해결하기 위해 나온 프로토콜이다

CS(Carrier Sense): 메시지 보내기 전에 현재 네트워크 상에 전송 중인 것이 있는 지 확인

MA(Multiple Access): 캐리어 감지를 하는데도 두개 이상의 호스트가 부득이하게 동시에 네트워크 사용

CD(Collision Detection): 충돌이 일어나면 검출하고 다른 호스트들에게 <mark>잼신호를 전송한다</mark>

## 4. 스위치

허브를 해결하기 위해 나온 데이터링크 계층의 네트워크 장비이다.

MAC 주소 테이블을 이용하여 MAC 주소 학습을 한다

### 4-1. 플러딩

송신을 한 데이터가 스위치에 오면 모든 수신기에 프레임을 수신한다. 이때 노드들은 자신의 MAC주소가 아닌 것들은 버리고 원래 보내려고 했던 수신기는 받는다

### 4-2. 필터링과 포워딩

필터링: 아닌 것들은 폐기하는 것

포워딩: 맞는 수신기

### 4-3. 에이징

일정시간동안 사용하지 않으면 테이블에서 삭제를 한다.

### 4-4. VLAN

스위치안에서 LAN을 나누고 싶을때(같은 스위치 안에서 소통을 아예 하지 않을 경우 스위치 낭비가 발생한다 이를 방지)

이럴 경우 다른 VLAN끼리 소통할 때 상위 네트워크 계층을 이용해야 한다

| 포트 기반 VLAN | MAC 주소 VLAN |
| --- | --- |
| 스위치를 트렁크 포트로 연결한다 | 말 그대로 MAC 주소로 VLAN을 나눈다 |
| 어떤 VLAN에 속하는 지 식별하는 802.IQ 프레임을 이용한다 |  |
